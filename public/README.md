# TeknoFixHub Public Assets

Folder untuk public assets yang dapat diakses dari web.

## 📁 Struktur

```
public/
├── images/
│   ├── logo.png
│   ├── favicon.ico
│   ├── products/
│   ├── blog/
│   └── ...
├── icons/
├── fonts/
└── index.html
```

## 🌐 Access

Assets dapat diakses di:
```
http://localhost:3000/images/...
http://localhost:3000/icons/...
http://localhost:3000/fonts/...
```

## 📝 Guidelines

- Optimize semua images
- Use correct format (jpg, png, webp)
- Compress files sebelum upload
- Update index.html jika perlu
