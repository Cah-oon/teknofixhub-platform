# TeknoFixHub Affiliate Program

Platform affiliate untuk earn money dengan mempromosikan produk TeknoFixHub.

## 📋 Program Details

### Komisi
- Tier 1: 5% (0-100 referral/bulan)
- Tier 2: 10% (101-500 referral/bulan)
- Tier 3: 15% (500+ referral/bulan)

### Fitur
- ✅ Unique affiliate link
- ✅ Dashboard performance tracking
- ✅ Real-time earning report
- ✅ Withdrawal management
- ✅ Marketing materials
- ✅ API untuk custom integration

## 🔗 Affiliate Links

Format:
```
https://teknofixhub.com/?aff=AFFILIATE_ID
https://teknofixhub.com/products/?aff=AFFILIATE_ID
```

## 💰 Earning Model

1. User klik affiliate link
2. User membeli produk dalam 30 hari
3. Commission automatically credited
4. Withdraw setiap bulan ke rekening bank

## 📊 Dashboard

Affiliate dashboard tersedia di: `/dashboard/affiliate`

### Metrics
- Total Clicks
- Total Sales
- Total Earnings
- Pending Balance
- Withdrawal History
