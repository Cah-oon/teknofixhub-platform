# TeknoFixHub Admin Dashboard

Admin panel untuk mengelola blog, produk, user, dan affiliate program.

## 📱 Fitur Admin

- ✅ Dashboard analytics
- ✅ Blog management
- ✅ Product catalog management
- ✅ User management
- ✅ Category management
- ✅ Affiliate program management
- ✅ Media library
- ✅ Settings management

## 🔒 Akses

Admin dashboard hanya bisa diakses oleh user dengan role 'admin'.

## 📦 Setup

```bash
npm install
npm run dev
```

Akses di: http://localhost:3001
