# TeknoFixHub Frontend

React.js frontend aplikasi untuk platform blog TeknoFixHub.

## 📦 Struktur Folder

```
frontend/
├── src/
│   ├── components/     # React components
│   ├── pages/          # Page components
│   ├── hooks/          # Custom hooks
│   ├── stores/         # State management (Zustand)
│   ├── services/       # API services
│   ├── styles/         # Global styles
│   ├── utils/          # Utility functions
│   ├── App.jsx         # Main app component
│   └── main.jsx        # Entry point
├── public/             # Static files
├── vite.config.js      # Vite configuration
├── tailwind.config.js  # Tailwind CSS config
└── package.json
```

## 🚀 Quick Start

```bash
npm install
npm run dev
```

## 📚 Pages

- **Home** - Landing page
- **Blog** - Blog listing
- **Article** - Detail artikel
- **Products** - Product catalog
- **About** - About page
- **Contact** - Contact form

## 🎨 Styling

Menggunakan Tailwind CSS untuk styling modern dan responsif.

## 📡 API Integration

Menggunakan Axios untuk API calls dengan base URL ke backend server.
