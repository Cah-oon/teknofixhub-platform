# TeknoFixHub API Postman Collection

Gunakan file ini untuk testing API menggunakan Postman.

## Import ke Postman

1. Buka Postman
2. Klik Import
3. Pilih file ini
4. Sesuaikan base URL

## Environment Variables

Buat environment dengan variabel:

```
base_url = http://localhost:5000/api/v1
token = {jwt_token}
```
